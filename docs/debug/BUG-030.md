## 1. scope-check.py's builder window leaves out the slot wait
- **Symptom:** a `supervisor:` commit of tests made while a builder that waited for the heavy slot still ran is counted as SUPERVISOR TESTS, not drift (launcher B1; tests-launcher B2; tests-guard B1).
- **Hypotheses:** (a) the window starts too late; (b) the window ends too early. Discriminating observation: where the run's `id` is taken. bridge-run.py sets `run_id` before it waits for the slot (the slot at its `acquire_heavy_slot` call), and `started = time.time()` after it, so `seconds` excludes the wait, which is logged apart as `waited` (tests/test_bridge_run_slot.py test_r040_seconds_excludes_wait pins this). The window `[id, id + seconds + 120]` therefore starts right and ends `waited` seconds early: (b).
- **Confirmed cause:** builder_windows (scope-check.py) ends a window at `id + seconds + 120`, ignoring `waited`.
- **Reproduction:** tests/test_hotfix25a_guard_scope_invisible.py::test_a_builder_window_counts_the_slot_wait (a row with `waited` 1500, `seconds` 600, started 1,800 s ago: SCOPE CLEAN today, must be drift; with `waited` 0 the same commit is the supervisor's, the precondition). test_a_builder_window_of_another_branch_is_not_counted pins the branch filter, which holds today.

## 2. roster-check.py's built_by counts a launch that never started
- **Symptom:** after a builder launch ends at exit 123 (`"slot": "not free"`), the roster's built-by model is that launch's, so the family rule lets a Review B of the family that really built the change run (launcher B2; tests-launcher B1).
- **Confirmed cause:** built_by takes the branch's last `kind: builder` row with a model, whatever its exit; the launcher writes a row for a launch that waited past the slot's bound and never started its command (exit 123, `slot` "not free", `seconds` 0).
- **Reproduction:** tests/test_hotfix25a_roster_launcher.py::test_a_launch_that_never_got_the_slot_did_not_build_the_change (a grok row, then a composer 123 row: built_by gives composer today, must give grok; review_family_refusal must refuse the grok review).

## 4. The brief is not checked again after the slot wait

- **Reproduction:** tests/test_task032_supervisor_launcher.py::test_bug030_the_brief_is_checked_again_after_the_slot_wait[True] (the brief rewritten while the launch waits: exit 0 today, must be 125 with no run and no log row; [False] runs). test_bug030_a_ceiling_refusal_does_not_wait_for_the_slot pins that the refusals come before the slot (tests-launcher S2), which holds today.
