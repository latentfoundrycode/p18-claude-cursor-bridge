Because `_link_walk_ok` refuses a value outside the launch folder, A's fallback to the absolute form named in the material cannot be reached for an accepted value, so round 7 builds the refusal instead. The leading `.` closes the one edge Review A found: a folder `-r` given as `./-r` would otherwise be handed as `-r`, which pnpm's parser may read as an option.
