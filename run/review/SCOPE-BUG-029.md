# SCOPE - BUG-029

BUG-029 is a fix increment (handoff/BUG-029.md, the fix variant of the brief), on branch fix/BUG-029 from origin/main after TASK-029 merged (PR #89). Two confirmed causes, both in bridge/cursor-bridge/bridge-run.py:

1. `head_of` stripped `.exe` and `.cmd` wherever they stood, so `kind_of` and `accepted` treated a file named `cursor-agent.exe.cmd` as the agent, while `resolve` swapped in the real agent only for an exact basename in AGENT_NAMES. Such a file ran as itself through cmd.exe, without the stripped environment, and labelled `--kind review` without the slot. A cursor-agent given by a path was accepted by its basename and silently swapped for the real agent. This is the security audit's advisory 1 from TASK-029's round 3 (docs/HARDENING.md, "TASK-029 (round 3's reviews ...)", "Taken next, as BUG-029"), and it predates TASK-029.
2. `acquire_heavy_slot` wrote `bridge-run: slot taken` before it published the holder record, so a waiter started on that line could say `held by unknown` (docs/HARDENING.md, TASK-029 round 4).

Review question for a fix diff: does this repair the named cause at the named mechanism, or does it make the symptom disappear? The builder is composer-2.5.
