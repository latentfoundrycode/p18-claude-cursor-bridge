## Objective

Fix the following confirmed defect: repair the named cause, nothing else. Round 9's head, a2f7ce6, went through the gate. Review A and the security audit both found the same blocking defect, and a finding both report is blocking. **Root cause, in one sentence.** `_pytest_config_dict_from_file` in `bridge/cursor-bridge/mutation-run.py` imports `iniconfig` from the program's own `sys.path`, which holds the bridge folder and the caller's `PYTHONPATH`, so it gets the installed iniconfig. The gate's `python -m pytest` and each mutant's pytest look first in the project's top folder (the copy root, which the program also puts on the child's `PYTHONPATH`), so a project with a top-level `iniconfig` has pytest read its configuration with the project's module while the program reads it with the installed one, and the two can pick different files.

**Evidence (round 9's Review A and security audit, reproduced by the supervisor).**
- The program's `import iniconfig` (inside the `.ini` and `.cfg` branches of `_pytest_config_dict_from_file`, around :838 and :856) resolves against the program's own `sys.path`: the bridge folder, then the caller's `PYTHONPATH`, then the installed packages.
- The gate's `python -m pytest`, started at the project's top, has the project's top folder first on `sys.path`. Each mutant's pytest runs with the copy root as its working folder, and `pytest_env` (around :1089) sets `run_env["PYTHONPATH"] = plugin_dir + os.pathsep + copy_root`. Either way pytest imports the project's top-level `iniconfig` before the installed one.
- Python imports the name `iniconfig` from more than one kind of top-level entry: `iniconfig.py`, an `iniconfig/` package, `iniconfig.pyc`, `iniconfig.pyd`, `iniconfig.cpython-312-x86_64-linux-gnu.so`. Any of them makes pytest's reading of `pytest.ini`, `.pytest.ini`, `tox.ini` or `setup.cfg` someone else's code, which the program does not run.

**Reproduction test (red on a2f7ce6, must pass).** In `tests/test_mutation_run_supervisor.py`: `test_task031_r10_a_top_level_iniconfig_in_the_project_is_refused`, parametrized `[iniconfig.py]` and `[iniconfig/__init__.py]`. Each fixture holds a root `tox.ini` with a `[pytest]` section. On round 9's code the run ends at the resolution check with exit 2 and "resolution check failed", not with the refusal. The test expects exit 2, the phrase `would shadow pytest's iniconfig` in the output, and no cache line.

`handoff/TASK-031.md` and `-r2.md` to `-r9.md` still govern everything this file does not change. Where an earlier brief disagrees with this file, this file wins. This round refines `handoff/TASK-031-r6.md` item 3 (B-3), "Find the copy's configuration file as pytest 9 does, at the copy's root", and `handoff/TASK-031-r9.md` Requirements 1 and 4.
