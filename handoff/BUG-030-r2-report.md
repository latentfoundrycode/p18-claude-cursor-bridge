## Summary

Round 2 repaired three defects in round 1's fix: module-level imports in `mutation-run.py` with broad exception recording and an early `run_main` exit 3 (no traceback), defensive `waited` handling in `scope-check.py` `builder_windows`, and a link check before copying conftest.py files in `archive_checkpoint`. The manifest was regenerated; CLI reference check passed unchanged.

## Cause 1

Restored `import tomllib` and `import bridge_env` at module level, each in `try`/`except Exception` that sets `_IMPORT_ERROR` and the failed name to `None`; `run_main` prints `mutation-run: internal error - ...` and returns 3 when `_IMPORT_ERROR` is set, so `SyntaxError` on damaged `bridge_env.py` and normal module import both behave as required.

## Cause 2

`builder_windows` uses `waited` only when `type(...)` is exactly `int` or `float` and the value is `>= 0`; all other values (including bool and negative numbers) count as 0.

## Cause 3

In `archive_checkpoint`, each conftest path is checked with `os.path.lexists` and `link_on_path(..., stop=workspace abs)` before copy; a link raises `Refuse` with `mutation-run: %r is reached through a link` and nothing is copied for that path.
