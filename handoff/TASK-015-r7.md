## Requirements
R7-1. **Only an exact `str` line gives pointer paths.** In `pointer_paths_from_module`, a line from `wc.file_lines` is read for `Sub-files:` and `Variants:` only if `type(line) is str`; any other line is skipped, as a line with neither prefix is. A pointer path is appended only if `type(p) is str` as well. Nothing else in the function changes.

R7-2. **Every exception the checker raises is caught where the checker is called.** The handler around the checker's load (`load_checker_module`), the handler around its use in `pointers_part`, and the guard of R6-1 in `safe_exc_type_name` catch `BaseException`, giving the lines they give today (`cannot be loaded (<name>)`, `cannot be used (<name>)`, `an exception`). The top-level handler at the end of the file stays as it is.

R7-3. **Nothing the checker writes reaches the hook's output.** While the hook loads the checker (`exec_module`) and while it uses it (the block of `pointers_part` inside the handler of R7-2), the standard output and the standard error are redirected to buffers that are discarded (`contextlib.redirect_stdout` and `contextlib.redirect_stderr` with an `io.StringIO`, from the standard library), and restored afterwards in every case, an exception included. The hook's own output is written after the redirection ends, as today.
