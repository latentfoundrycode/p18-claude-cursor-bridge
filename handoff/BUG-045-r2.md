**Root cause 1, in one sentence:** `git_subcommand(w)` (`bridge/cursor-bridge/permission-guard.py:2424-2436` as of round 1's tree) skips `-C`, `-c`, `--git-dir`, `--work-tree`, `--namespace` and `--exec-path` with one value word and any other dash word alone, so a git global option it does not know that takes its value as the next word (`--attr-source <tree>`, `--super-prefix <path>`, or any option a later git adds) makes that value the subcommand, and every refusal that reads `sub` (hook skippers, force push, `worktree remove`) is skipped while git runs the real subcommand.

**Root cause 2, in one sentence:** `_alias_names_refused(a)` (lines 2036-2046, with `_alias_value_prefix` at 2010-2033 and `_ALIAS_PREFIXES = ("worktree", "pr", "push", "api")` at line 69) refuses an alias defined in the command whose value names `worktree remove`, `pr merge`, a forced push, `api` or a `!` shell command, and none whose value is another hook-skipping subcommand, so `git -c "alias.cm=commit --no-verify -am" cm x` passes, and with the lone-help exemption `git -c core.hooksPath=nohooks -c "alias.cm=commit -am" cm -h` passes while git commits with its hooks off.

**Evidence** (docs/debug/BUG-045.md, "Round 1's findings", 2026-11-16):
1. `git_subcommand("git --attr-source HEAD commit --no-verify -m x".split())` returns `('HEAD', ['commit', '--no-verify', '-m', 'x'])`, and the guard passes `git --attr-source HEAD commit --no-verify -m x`, `... push --force origin main` and `... worktree remove wt`; so does `git --super-prefix x/ commit --no-verify -m x`, and `git --bogus-new-option x commit --no-verify -m x` passes.
2. The audit ran git: in a scratch repository whose pre-commit hook exits 1, `git --attr-source HEAD commit -a --no-verify -m second` exits 0 and commits, and `git --attr-source HEAD worktree remove <wt>` removes the worktree.
3. `git -c "alias.cm=commit --no-verify -am" cm x` passes under both the Bash and the PowerShell tool; `git -c core.hooksPath=nohooks -c "alias.cm=commit -am" cm -h` passes and git commits with subject `-h`, the hooks off (Review A, on git 2.53).

def git_subcommand(w):
    """The git subcommand and its arguments, skipping global options such as -C <dir>."""
    i = 1
    while i < len(w):
        tok = w[i]
        if tok in ("-C", "-c", "--git-dir", "--work-tree", "--namespace", "--exec-path"):

            continue
