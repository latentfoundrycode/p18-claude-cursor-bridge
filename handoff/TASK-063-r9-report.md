## Summary

Round 9 keeps round 8's grammar and refuses seven forms that grammar still read: a word an MSYS program started by PowerShell or cmd would parse again, an empty or edge-whitespace argument of powershell.exe, an env or sudo assignment whose name is not an identifier, an assignment that makes a child bash run code or selects a multibyte locale, a powershell inner command whose word holds both `/` and `:`, a find clause whose command is the found file, and the extra launchers (gpg-agent, gpg-connect-agent, rundll32, pcalua, runas, wmic, ssh-agent with a command, and ssh `-o` keys that run a command). `chain_reason` takes `slash_ok` as a keyword-only argument with no default.

## Requirements

1. `_reparse_applies` and `_reparse_after`, called from `_walk_to_command` for each MSYS prefix and for the command word (the first word when the mode is cmd), refuse a later word that holds a quote, brace or glob mark, a backslash together with whitespace, or that begins with `~` or `@`; under bash this attaches only to a `bash` or `sh` whose command word holds `/` or `\` and does not begin `/usr/bin/` or `/bin/`.
2. `_ps_arg_edge` and `_ps_switch_walk` refuse every argument of a `powershell` or `pwsh` wrapper that is empty or begins or ends with whitespace, and `_ps_is_switch` does not treat such a word as a switch.
3. `_apply_assignment` with strict set, used by `_walk_env` and by `_take_assignments` after `sudo`, treats a word that holds `=` and does not begin with `-` as an assignment, and refuses a name that is not an identifier.
4. `_apply_assignment`, used for leading assignments as well as env and sudo, refuses `BASH_ENV`, `ENV`, `PS4`, `SHELLOPTS`, `BASHOPTS`, `PROMPT_COMMAND` and a name beginning `BASH_FUNC_` in any case, and refuses `LANG`, `LC_ALL` or `LC_CTYPE` unless the value is `C`, `POSIX`, or ends in `.UTF-8` or `.utf8`.
5. `_check_word_list` refuses a `powershell` or `pwsh` inner command read with `slash_ok` false when one of its words holds both `/` and `:`.
6. `_find_brace_refusal`, called from `_check_word_list` for each find clause, refuses `{}` as or inside the command word at any depth under the clause, and any word that holds `{}` without being exactly `{}`.
7. `REFUSED_CMD_WORDS` now includes `gpg-agent`, `gpg-connect-agent`, `rundll32`, `pcalua`, `runas` and `wmic`; `_ssh_agent_refusal` allows only ssh-agent's own options and refuses a command after them; `_ssh_option_refusal` refuses an `-o` key of `ProxyCommand`, `LocalCommand`, `PermitLocalCommand` or `KnownHostsCommand`.
8. `chain_reason` declares `slash_ok` keyword-only and no longer fills it in when the caller leaves it out.
9. The seven cases below are in `tests/test_permission_guard_a4.py`, each named R-082, and each refusal asserts the words of its own reason. The subprocess calls go through `run`, which passes `creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0)` and a timeout on the same line.
