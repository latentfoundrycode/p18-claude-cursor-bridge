# BUG-042: the conformance check reads the weekly scan as the gate

## Objective
Fix the following confirmed defect — repair the named cause, nothing else.

- **Root cause:** `main()` in `bridge/cursor-bridge/conformance-check.py` reads every workflow under `.github/workflows/` as the gate: `steps` is extended from every one of them and `scanner_lines` is taken from `wf_text`, the join of all of them, so the unguarded OSV-Scanner step of the weekly `dependency-scan.yml`, which release T puts in every project, alone satisfies the floor `OSV-Scanner in the gate`.
- **Evidence (stage T2's review, round 1, Review A's ci part, reproduced on scratch projects):** a gate with no OSV step plus the weekly file reads OK; a gate whose OSV step is guarded by `if:` plus the weekly file reads OK; each reads MISSING without the weekly file. The weekly file's pinned download also hides the `OSV-Scanner version pinned` NOTE for an unpinned gate step.
- **Reproduction tests, in `tests/test_bug042.py`, that fail on the code today and must pass:** `test_bug042_a_gate_with_no_osv_step_stays_missing_beside_the_weekly_file`, `test_bug042_a_guarded_gate_step_stays_missing_beside_the_weekly_file`, `test_bug042_an_unpinned_gate_step_keeps_its_note_beside_the_weekly_file`, `test_bug042_the_weekly_file_alone_is_no_gate`, `test_bug042_the_weekly_file_is_known_by_its_name_in_either_form`, `test_bug042_the_guard_s_docstrings_name_the_deleted_snapshot`.
- **Invariants that pass today and must stay green:** `test_bug042_negative_a_gate_step_beside_the_weekly_file_is_ok`, `test_bug042_negative_an_action_in_the_weekly_file_still_counts_for_the_pin_row`, and every test in `tests/test_conformance_check.py`.

The brief also carries one text repair the same review found: BUG-041 made a snapshot deleted after it was taken, its hash copy standing, GATE-INTEGRITY with exit 1, and left two docstrings of `bridge/cursor-bridge/review-guard.py` saying otherwise. The last reproduction test above pins their words. No code of that program changes.

Satisfies: R-052 — every project has a weekly scheduled OSV-Scanner workflow, and the floor's steps stand in the gate: the weekly scan is a second workflow and answers for no floor of the gate.
