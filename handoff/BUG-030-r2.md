## Requirements
1. **Cause 1 (mutation-run.py imports):** put `import tomllib` and `import bridge_env` back at module level, where they stood before round 1 (`bridge_env` after the `sys.path` insert), each inside a `try:` whose `except Exception as e:` records the failure in a module-level name (for example `_IMPORT_ERROR = e`) and sets the name that failed to `None`; a clean import leaves `_IMPORT_ERROR` as `None` and both modules bound, so every function works when the program is loaded as a module. Remove round 1's import block from `run_main`; instead `run_main` begins by checking the recorded failure and, when there is one, prints one line `mutation-run: internal error - <what failed>` to stderr (the exception's text, naming the module where the text does not) and returns 3, before `main` runs. No traceback is printed. Every other exit code and message is unchanged.
2. **Cause 2 (scope-check.py `builder_windows`):** `waited` is used only when its type is exactly `int` or `float` (never `bool`) and its value is 0 or more; any other `waited` (a bool, a negative number, a string, null, missing) counts as 0. Nothing else in the function changes; the docstring's statement of the window's end stays true.
3. **Cause 3 (mutation-run.py `archive_checkpoint`):** before a working-tree conftest.py on the way to a new test is read or copied, refuse it when it, or any folder between it and the Workspace, is a link, as `validate_untracked` does: `link_on_path(<its full path>, stop=<the Workspace's absolute path>)` true means `raise Refuse("mutation-run: %r is reached through a link" % <its relative path>)` (the message names the path, which ends `conftest.py`), and nothing is copied for it. Test for existence with `os.path.lexists`, so a link that leads nowhere is refused too, not skipped. A conftest.py that is not a link and is a file is copied as round 1 copies it; one that does not exist is left as the archive has it. The refusal is made inside `archive_checkpoint` (the test calls it directly), before that conftest.py is copied.
