## Context
- Rounds 1 and 2's briefs hold wherever this file does not change them. Read `trace-check.py` whole first.
- On Windows, `os.path.islink` is false for a junction; `os.path.isjunction` (Python 3.12, which CI pins) is true for it. A reparse point of any kind shows as `stat.FILE_ATTRIBUTE_REPARSE_POINT` in `os.lstat(p).st_file_attributes` (Windows only; the attribute does not exist elsewhere). `os.path.realpath` follows links (and a broken link's target) before it returns, so it can open a network path a link names before any containment test runs.
- Windows drops a trailing `.` from a path component, and maps the device names `CON`, `PRN`, `AUX`, `NUL`, `COM1` to `COM9` and `LPT1` to `LPT9`, in any case and with or without an extension (`com1.md`), to devices, so such a segment can "exist" while naming no file.
