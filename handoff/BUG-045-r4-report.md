## Summary

`force_push_reason` now refuses a push word whose part before `=` is a prefix of `--mirror` from three characters up, and a single-dash cluster of ASCII letters plus the characters `4` and `6` that holds `f`, using the refusal texts the function already returned. `_short_letters_hold` takes an extra `digits` argument that defaults to empty, so commit's `-n` stays a letters-only reading. Round 3's PowerShell alias case now accepts either `alias` or `literal double quote` in the reason.

## Causes

The single 4-character floor no longer covers `--mirror`: a part before `=` that is a prefix of `--mirror` is refused from 3 characters, while a part that is a prefix of `--force`, `--force-with-lease` or `--force-if-includes` is still refused only from 4 characters.
A short-flag cluster is no longer letters only on push: `force_push_reason` passes the characters `4` and `6` into `_short_letters_hold`, so a cluster that holds `f` together with those digits is a force push, and any other character still keeps the word out of that reading.

## F10

`force_push_reason` (lines 2409-2423) at line 2417 refuses when the part before `=` is a prefix of `--mirror` and at least 3 characters long, or at least 4 characters and a prefix of one of `long_opts`, so `--m` is refused and a 3-character `--f` is not, and the whole-word line (2412), the `--force` abbreviation line (2414) and the forcing-refspec lines (2421-2422) are unchanged.

## F11

`_short_letters_hold` (lines 2009-2019) changed: it takes `digits=""`, and a character in `digits` is allowed beside ASCII letters; `force_push_reason` line 2419 calls it as `_short_letters_hold(a, "f", "46")`. The default is empty, so `ch in digits` adds nothing and `hook_skipper_option` line 2354, which is byte-identical to round 3 and still calls `_short_letters_hold(a, "n")`, reads commit's `-n` as letters only.

## F12

`test_bug045_a_quoted_alias_under_powershell_is_refused` keeps its four ids and commands and now accepts exit 2, `refused` in the reason, and either `alias` or `literal double quote` in it. A value that holds a literal double quote is refused by the PowerShell reader before the alias loop, as round 2's tree did; the docstring says that.
