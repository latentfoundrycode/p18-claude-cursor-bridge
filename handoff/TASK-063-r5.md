## Requirements

1. **One flat reader.** One function reads the command once, left to right, in time linear in its length (no regular expression over the rest of the text, no slicing to the end, no join of what was already read, at any character), and returns either the unreadable reason or the list of commands, each command as: its words (quotes removed, escapes applied, redirections and their targets taken out), the separator that ended it, whether it is a later stage of a pipeline, and whether its last word ran straight into an unquoted single `&` (requirement 6's `gh api` remedy). There is no stack: no construct opens a level. The same function reads in three modes, bash, PowerShell and cmd (requirements 2, 4 and 5), a parameter choosing the mode; there is no second function that reads quotes. Every caller takes its commands and words from this reading; nothing reads a command's text again, and there is no other scanner of quotes, no tokenizer, no shlex. The reader never raises.

2. **Bash, readable** (the Bash tool, and the inner command of a `bash`, `sh` or `dash` wrapper):
   - plain characters; the blanks are space and tab only;
   - single quotes: everything up to the next single quote is literal, a new line included;
   - double quotes: a backslash escapes `"`, `\` and a new line (a backslash and a new line are removed together); any other backslash is literal; a `$` or a backtick inside them is unreadable;
   - outside quotes, a backslash makes the next character literal, except that a backslash followed by a new line removes both and joins the parts (`git push --for\` new line `ce` is `--force`); a backslash before a carriage return escapes the carriage return;
   - adjacent quoted and plain parts are one word (`--fo"rce"` is `--force`); `~` is a plain character;
   - `{` and `}` only as `{}` or as `{` followed by one or more of `[A-Za-z0-9_-]` and `}`, inside a word or as a whole word (`HEAD@{1}`, `stash@{0}`, `{owner}/{repo}`, `find -exec echo {} +`); a word that is wholly `{name}` and is directly followed by `<` or `>` is a named descriptor (`exec {fd}>out.txt`) and is unreadable;
   - the separators `;`, `&&`, `||`, `|`, `|&` (read as `|`), a single `&` that is not part of a redirection, and a new line; an empty command (a separator after another, a leading `&`, blank lines) is skipped;
   - redirections, each taken out of the words with its target wherever it stands (before the command name too): an optional run of digits, then `<`, `>`, `>>`, `>|`, `<>`, `<&`, `>&`, `&>`, `&>>`; after `<&` or `>&` a run of digits or `-` is the target, any other word is a file target; the target is the next word of the same grammar (quoted parts included, so `>'--help'` takes `--help` out of the words);
   - a `#` that starts a word outside quotes begins a comment to the end of its line; nothing inside a comment is read (a backslash before its new line included);
   - leading `NAME=word` assignments (`NAME` is `[A-Za-z_][A-Za-z0-9_]*`); a command of assignments alone passes.

   - an unquoted `(` or `)`; an unquoted `*`, `?` or `[`; an unquoted `{` or `}` other than requirement 2's forms (so brace expansion, with or without a prefix or suffix, and a brace group);

[[ ]] coproc`), and every builtin except `cd`, `echo`, `printf` (unless an argument is `-v`), `pwd`, `true`, `false`, `:`, `exit` and `type`; the builtins are `. : [ alias bg bind break builtin caller cd command compgen complete compopt continue declare dirs disown echo enable eval exec exit export false fc fg getopts hash help history jobs kill let local logout mapfile popd printf pushd pwd read readarray readonly return set shift shopt source suspend test times trap true type typeset ulimit umask unalias unset wait`; `eval`, `exec`, `command` and `builtin` are wrappers (requirement 5), not refused.    - under either tool (the bash and the PowerShell reading alike): `xargs`, `start`, `wsl`, `mintty`, `winpty`, `strace`, `dash`, `zsh`, `ksh`, `fish`, `csh`, `tcsh`, `ash`, `busybox` as a command word (with or without `.exe`); an assignment whose name begins `GIT_CONFIG` (any case); a word `--config-env` or beginning `--config-env=`; a wrapper option outside its table (requirement 5); `env -S` and `--split-string`; requirement 5's prefixes are read under either tool;
