# TASK-060: The strip's names: a key file's home variables and the secret-like names (R-080)

## Objective
`bridge/cursor-bridge/bridge-run.py` (the launcher) strips the environment of a run (`--strip`, and always for a `cursor-agent` run) through `bridge_env.stripped_env`, and then applies a key file's lines (`--key-file`) on top of the stripped environment. Two gaps let a run get what the strip means to withhold. First, a key file line naming a home variable (`USERPROFILE`, `HOME`, `HOMEDRIVE`, `HOMEPATH`, `APPDATA`, `LOCALAPPDATA`) is applied after the strip and points the run back at the owner's real profile, undoing the agent home. Second, the secret-like name test (`bridge_env.SECRET_LIKE` / `secret_like`) misses common credential names (`GITHUB_PAT`, `AWS_CREDS`, `GH_AUTH`, `DATABASE_URL`, `SSH_AUTH_SOCK`), keeps every `CURSOR_` name for every stripped run although only `cursor-agent` needs Cursor's own key, and stands in three copies (bridge_env.py, an awk copy in `cursor-agent.shim`, and `ENV_SECRET` in `conformance-check.py`). This increment refuses a key file that names a home variable before the run starts; widens the one name test in `bridge_env.py`; withholds a secret-like `CURSOR_` name from test and driver runs while builder and review runs keep it; makes `conformance-check.py` read bridge_env's test instead of its own copy, its floor on keys within the builder's reach naming the new forms; makes the shim's awk test follow the new forms; and rewrites D-004's note "Stripped environment" so it describes what the code does. The supervisor's acceptance tests are written and committed; your work is to make them pass without breaking the existing ones.

Satisfies: R-080 - The strip cannot be undone by a key file, and its name test knows more names (J10, J11): a key file that names `USERPROFILE`, `HOME`, `HOMEDRIVE`, `HOMEPATH`, `APPDATA` or `LOCALAPPDATA` is refused before the run (exit 125, the name printed, the value never); the secret-like name test, one copy in `bridge_env.py` read by the launcher and by `conformance-check.py`, also matches `PAT`, `CREDS` and `AUTH` as name parts, `DATABASE_URL` and `SSH_AUTH_SOCK`, and a secret-like `CURSOR_` name is withheld from test and driver runs.
