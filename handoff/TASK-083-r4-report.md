## Summary

`gh_words` now takes a word for gh's group, and for the subcommand after any group other than `api`, only when the whole word is a command name of ASCII letters, digits and hyphens, and marks every other word there (the empty word among them, and an option that is not last) with the existing `INNER_UNREADABLE` sentinel. `check` refuses that sentinel through `_cannot`, and `state_changing` counts it as state-changing even when the word is `--version`, which `GH_READ` names. `merge_reason` refuses an empty pull-request number with the no-number message. The round-3 chain case now uses `gh --version` beside an allowed `git status && gh pr view 12`.

## K1

`gh_words` (2056-2085) appends a word as the group, or as the subcommand after a group other than `api`, only when the whole word matches `[A-Za-z0-9][A-Za-z0-9-]*` (2078-2080); an option that is not the last word (2074-2076) and any other word there return `(INNER_UNREADABLE, word, [])`. The gh branch of `_check_word_list` (2317-2322) refuses that sentinel with `_cannot`, keeping round 3's option text when the word begins with `-` and otherwise naming the word with `repr`, and the gh branch of `state_changing` (2393-2396) counts the sentinel as state-changing.

## K2

`merge_reason` (2583-2585) refuses an empty number with the no-number message `gh pr merge without the pull request's number: gh pr merge <n> --squash --match-head-commit <sha>`, and `test_r083_r4_an_empty_pull_request_number_is_no_number` (310-313) asserts that message under Bash in a repository that holds both records for the head.

## K3

`test_r083_r3_an_equals_form_before_the_bare_option_clears_it_and_the_option_is_state_changing` (295-307) now refuses the chain `git status && gh --version pr view 12`, whose option `GH_READ` names so only `state_changing`'s unreadable branch refuses it, and allows `git status && gh pr view 12` in the same workspace.

## Cause

`gh_words` had appended every word that did not begin with `-`, so the empty word became the subcommand and `merge_reason` never ran; a word is now the group or the subcommand only where it is a command's name, and `check` refuses every other word there.
