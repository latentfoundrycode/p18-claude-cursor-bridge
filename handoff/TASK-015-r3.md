R3-2. **Nothing a checker function returns is printed as a path.**
- A table error names its file by comparing the returned path with `slash(wc.DEFAULT_OPEN)` and `slash(wc.DEFAULT_REGISTRY)` (the checker's own `slash`): equal to the first, the line names `~/.claude/cursor-bridge/workflow/open-list.md`; equal to the second, `~/.claude/cursor-bridge/workflow/extension-points.md`; anything else gives the line `~/.claude/cursor-bridge/workflow-check.py: cannot be used (an unexpected table error)`.

The checker's own reasons today (`does not exist`, `missing heading ## Product types`, `missing column Key`, an OS error's `strerror`) contain none of them.
