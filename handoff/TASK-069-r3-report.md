## Corrections

1. A pull request is merged by its closing number alone. `_pr_name` (lines 571-579) is the reserved form `PR-<n>`, a whole number from 1 parsed with `int`. In `_pace_names` (lines 733-827) the loop that builds `fold` and `own` (lines 751-778) drops those tokens before choosing a fold target (lines 765-769) and before occupying a commit in untracked mode (lines 760-764). A close that names a counted name is the earliest fold (lines 770-772); a close that names none is the earliest own commit (lines 773-774). Where any close is an own commit, that pull request is not folded (lines 775-778), so an earlier fold of the same number does not hide it. The merge loop (lines 810-826) skips a `PR-<n>` token (lines 812-814) and marks `PR-<n>` merged only at its own commit (lines 820-826).
2. A pass line with a word outside the causes is `unstated`, not dropped. `_parse_pass_line` (lines 589-610) sets the cause to `unstated` when the captured cause is not in `bridge_env.ROUND_CAUSES` (lines 607-609). A bad stamp, name, round number or reviewer kind is still refused.
