- bridge/cursor-bridge/records-migrate.py

## Summary

The migration now refuses header-less build plans that plan-check and completion-check would reject after heading: increments outside any `##` stage (F1) and any body R-id read by `plan_r_ids_outside_headers` that the composed header’s satisfies union would omit (F2), using the brief’s fixed `cannot read` texts. Plan read-back and the in-memory `--check` path call `_validate_plan_readers`, which runs `plan_header_refusal` and the same satisfies union check (F3). Enumeration escapes the project root for glob (F4), and `merge_unit` with no prose value serializes as `null` not `[]` (F5). Supervisor reproduction cases and additional builder tests were added below the marker in `tests/test_bug044.py`.

## Named cause

Read-back formerly stopped at `header_agrees` against the same `fallback_for` reading that composed the header, so it never applied the headed readers’ shape rule or completion-check’s outside-header satisfies scan; F1 and F2 refuse such plans before write, and F3 runs those reader rules on the composed bytes in `_validate_read_back`.

## Fixes F1–F5

- **F1:** `_plan_outside_stage_refusal` (lines 284–292) and `main` (lines 733–737) list the first `outside_stage` increment and skip writing; pinned by `test_bug044_a_plan_heading_outside_any_stage_is_listed_cannot_read_and_not_written` and builder CRLF/addendum cases.
- **F2:** `_plan_satisfies_coverage_refusal` (lines 295–302) and `main` (lines 756–761) compare `plan_r_ids_outside_headers` to `_plan_satisfies_union`; pinned by `test_bug044_a_bold_satisfies_line_is_listed_cannot_read_and_not_written` and builder shape parametrization.
- **F3:** `_validate_plan_readers` (lines 510–524) called from `_validate_read_back` (lines 527–545) for `build-plan`; pinned by F3 monkeypatch tests below the marker and the supervisor gate cases.
- **F4:** `enumerate_records` uses `glob.escape(root)` at line 244; pinned by `test_bug044_a_glob_character_in_the_root_s_path_still_finds_the_plans`.
- **F5:** `_list_or_null_spec` and null branches in `_dump_lines` (lines 107–108, 121–123) and `_dump_list_of_mappings` (lines 163–164, 174–175); pinned by `test_bug044_a_brief_with_no_merge_unit_line_is_written_merge_unit_null` and `test_bug044_f5_brief_with_merge_unit_line_keeps_list_not_null`.
