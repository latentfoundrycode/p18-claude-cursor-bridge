**Root cause, in one sentence.** A `.pyc` records its source's size and modification time to the second, and every pytest `bridge/cursor-bridge/mutation-run.py` starts in the copy may write bytecode under `__pycache__` there, so a same-size mutant written within the second after its original was compiled runs the stale bytecode (a false survivor), and an original restored within the second after the mutant was compiled leaves the next mutant's tests running the last mutant's code (a false kill or a false error).
