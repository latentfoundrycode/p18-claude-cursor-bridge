## Summary

The launcher now snapshots git `config`, `info/attributes`, `config.worktree`, and hooks-folder file entries (by SHA-256) immediately before starting a `test` or `driver` child and again after the child ends without further git calls, printing sorted `bridge-run: GIT-CONFIG <path> <new|removed|changed|unreadable>` lines on stderr before the exit line (or alone when the child exits 124); helpers live beside `boundary_listing`, with four new R-081 cases in `tests/test_bridge_run.py`, and `main()` creates a missing `run/` folder before `write_log` so the acceptance row comparison can pass.

3. `git_before = git_watch.before()` runs only after the heavy slot and driver re-checks, immediately before `subprocess.Popen`; no git subprocess is used on refusal paths that return before that point.
4. `GitConfigWatch.after()` reuses the same absolute file list and hooks directory list from `__init__` and calls `_snapshot()` with no `git` subprocess.
5. `git_config_changes` emits one stderr line per path; display paths use `_git_display_path` relative to the common git folder’s parent with forward slashes, and when `relpath` would escape with `..` the absolute path is normalized with forward slashes; lines are sorted by path.
6. `report_git_config()` runs on the limit path before `report_boundary()` and the exit line, and on the normal path before boundary/exit; when the child exits 124 inside the limit only GIT-CONFIG lines are written.
7. Exit code, log `entry` fields, and limit behaviour are unchanged except that `main()` may `makedirs` for `run/` before `write_log` when the folder was missing; snapshot failures are swallowed inside `GitConfigWatch` and `report_git_config`.
8. Hooks `listdir` entries that are directories are skipped, so an unchanged subdirectory produces no line on every run.
9. Four tests named `test_r081_*` in `tests/test_bridge_run.py` cover limit path, child exit 124, single hooks line, and refused driver with scratch repos under `tmp_path` and `GIT_CEILING_DIRECTORIES`.
10. Ran `python tools/make-manifest.py` and `python tools/dump-cli.py --check`; module docstring and `VERSION` unchanged.
