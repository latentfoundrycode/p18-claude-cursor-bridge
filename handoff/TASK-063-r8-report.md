## Summary

Round 8 makes the permission guard refuse shells that read standard input (a PowerShell `-command` or `-file` aimed at `-` or at nothing, a bare `powershell`, cmd `/k`, and a `bash`/`sh` script whose input is a pipe, an input redirection, or a re-read of one of those), passes `slash_ok` down from the first reading instead of recomputing it, refuses PowerShell words whose quotes, trailing backslash or comma do not say what the program receives, keeps only the PowerShell value switches 5.1 knows, stops the cmd mode from treating a prefix as the command word while later checks still see through prefixes, gives `find` the right number of option words and refuses an `-exec` consumed as a value, and replaces the joined-command `.*` searches and the two-character deadline skip with linear tests.

## Requirements

1. `_ps_switch_walk` refuses a `-command` prefix and `-file`/`-f` whose next word is missing or `-`, and a `powershell` whose switches leave no command and no file; `_cmd_switch_walk` refuses `/k` and `//k`; `_read_bash`, `_read_powershell` and `_read_cmd` mark a later pipeline stage and an input redirection, and `_bash_reads_stdin` refuses a script word when that `fed` flag is set, including on a re-read from `_check_one`.
2. `check` sets `slash_ok` once, true only for the PowerShell tool, and `_check_one` passes that parameter into every re-read; it becomes false for everything under a `bash`/`sh` command string, an `eval`, a `find` clause or a prefix wrapper, a cmd inner command is read with false, and a `powershell` inner command inherits the caller's value. `slash_ok` is never computed from the tool below the first reading. `_command_changes` and `_chain_from_words` pass the same parameter.
3. `_read_powershell` refuses a quote that is not the first character of the word or a word that continues after its closing quote, a word that holds a blank and ends in a backslash, and an unquoted comma; a leading `.` is a call operator only when it is its own word.
4. `PS_VALUE_SWITCHES` is exactly `-executionpolicy`, `-ep`, `-ex`, `-windowstyle`, `-w`, `-inputformat`, `-if`, `-outputformat` and `-of`, and `_ps_switch_walk` refuses every other switch that is not in the round 5 and round 7 tables.
5. `_walk_to_command` skips assignments and prefix wrappers when the mode is cmd, and `_cmd_word_refusal` applies `_cmd_name_refusal` to the first word; `_check_word_list` still walks prefixes for the refused actions, rule 8 and the launchers, so `cmd //c env git worktree remove y` is still refused with `worktree` in the reason.
6. `_find_arg_count` gives `-fprintf` two words, `-newer` plus two letters and `-files0-from` one word, and a bare `-O` none; `_find_clauses` refuses an `-exec`, `-execdir`, `-ok` or `-okdir` word consumed as an option value.
7. `_husky_git_mutation` finds `\bgit\b` and then searches commit, push or merge only after that match; `_alias_names_refused` strips the value after `=` and compares a prefix, keeps `worktree\s+remove|pr\s+merge`, and searches `--forc|-f\b|\+` only after `push\b`; `_short_letters_hold` replaces the short-flag tests. No `.*` regular expression runs over a whole command. `_too_long` runs after each of those checks.
8. `_deadline_at` tests `_too_long` when the reader's position reaches the next mark and then moves that mark 4096 characters on, in `_read_bash`, `_read_powershell` and `_read_cmd`, so a step of two characters cannot skip a test.
9. `_skip_assignments`, `_bash_interactive` and `_wrapper_opt_refusal` are deleted; nothing called them.
10. The eight cases below are in `tests/test_permission_guard_a4.py`, each named R-082, and both `run` helpers (`tests/test_permission_guard.py` and `tests/test_permission_guard_a4.py`) pass `creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0)` and a timeout on the `subprocess.run` line.

## Cases added or changed

- `test_r082_r8_req1_a_script_fed_by_a_pipe_is_unreadable` — `echo x | env -C / bash dev/stdin`, expects `cannot read`. Round 7 leaves the PowerShell and cmd pipe flag false and treats a relative `dev/stdin` as a script file, so the command passes.
- `test_r082_r8_req2_single_slash_behind_a_prefix_is_unreadable` — `echo x | env powershell -c cmd /c echo hi` under PowerShell, expects `cannot read`. Round 7 recomputes `slash_ok` from the tool on the inner read, so `/c` is accepted and `echo hi` passes.
- `test_r082_r8_req3_a_quote_not_at_the_start_of_a_word_is_unreadable` — `echo a'b c'` under PowerShell, expects `cannot read`. Round 7 keeps a word that starts in plain text and continues into a quote, so this passes.
- `test_r082_r8_req4_settingsfile_is_not_a_value_switch` — `powershell -settingsfile 'x; git worktree remove y;' echo`, expects `cannot read`. Round 7 lists `-settingsfile` as a value switch, skips the quoted text, and lets `echo` pass.
- `test_r082_r8_req5_cmd_takes_no_prefix` — `cmd //c powershell/command git status`, expects `cannot read`. Round 7 walks prefixes in the cmd mode, so `powershell/command` is the prefix `command` and `git status` passes.
- `test_r082_r8_req6_fprintf_takes_two_words` — `find . -maxdepth 0 -fprintf out.txt -name -exec git worktree remove y ';'`, expects `worktree`. Round 7 lets `-fprintf` take one word, so `-name` consumes `-exec` and the removal never starts.
- `test_r082_r8_req7_a_long_husky_command_is_the_removal` — `HUSKY=0 echo ` followed by `git ` 32000 times, then `; git worktree remove y`, expects `worktree` within 2 seconds. Round 7 runs `\bgit\b.*\b(commit|push|merge)\b` over that joined command, which does not finish inside the hook's time.
- `test_r082_r8_req8_a_two_character_step_still_meets_the_deadline` — `_read_bash` of `echo ` plus `\x` 2100 times, with the module clock still inside the limit on the first two calls and past it on the third, expects `too long`. Round 7 tests the clock only when `i & 4095 == 0`, and a two-character step from 4095 to 4097 never calls it again before the read ends, so the command is returned as readable.
- No test case in `tests/test_permission_guard.py` changed its command or its expected result. Its `run` helper, and `run` in `tests/test_permission_guard_a4.py`, now pass the window flag and a timeout.
