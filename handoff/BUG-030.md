# BUG-030 — stage B5's review, round 1: eight confirmed program defects

## Objective
Fix the following confirmed defect — repair the named cause, nothing else. This is a group of eight confirmed causes found by stage B5's review, round 1, each read from the program at origin/main 03f1041 and shown by a reproduction test the supervisor wrote first. The source of truth is `docs/debug/BUG-030.md` (read it whole before you start); each cause, its evidence and its reproduction test are carried below. Each fix is the minimum that removes its cause; nothing else changes "while you are there".

1. **scope-check.py's builder window leaves out the slot wait.** Root cause: `builder_windows` (`bridge/cursor-bridge/scope-check.py`) ends a window at `id + seconds + 120`, ignoring `waited`. Evidence: bridge-run.py sets `run_id` before it waits for the slot (its `acquire_heavy_slot` call) and `started = time.time()` after it, so `seconds` excludes the wait, which is logged apart as `waited` (tests/test_bridge_run_slot.py `test_r040_seconds_excludes_wait` pins this); the window `[id, id + seconds + 120]` starts right and ends `waited` seconds early. Reproduction: `tests/test_hotfix25a_guard_scope_invisible.py::test_a_builder_window_counts_the_slot_wait` (fails today); `::test_a_builder_window_of_another_branch_is_not_counted` pins the branch filter (passes today, must keep passing).
2. **roster-check.py's built_by counts a launch that never started.** Root cause: `built_by` (`bridge/cursor-bridge/roster-check.py`) takes the branch's last `kind: builder` row with a model, whatever its exit; the launcher writes a row for a launch that waited past the slot's bound and never started its command (exit 123, `"slot": "not free"`, `seconds` 0). Reproduction: `tests/test_hotfix25a_roster_launcher.py::test_a_launch_that_never_got_the_slot_did_not_build_the_change` (a grok row, then a composer 123 row: `built_by` gives composer today, must give grok; `review_family_refusal` must refuse the grok review).
3. **The launcher spends a class line on a launch that never started.** Root cause: `builder_review_refusal` (`bridge/cursor-bridge/bridge-run.py`) collects `class_used` from every row of the brief's ID with `lift` "class", the 123 row included. Reproduction: `tests/test_task032_supervisor_launcher.py::test_bug030_a_launch_that_never_got_the_slot_spends_no_class_line` (refused today, must run lifted). The supervisor's ruling: a 123 row's branch claim stands, pinned by `::test_bug030_a_launch_that_never_got_the_slot_still_claims_its_branch` (passes today, must keep passing).
4. **The brief is not checked again after the slot wait.** Root cause: `main` (`bridge/cursor-bridge/bridge-run.py`) reads and judges the brief once, in `builder_review_refusal`, before `acquire_heavy_slot`; the driver kind's program is checked again after the slot (TASK-029 r4), the brief is not. Reproduction: `tests/test_task032_supervisor_launcher.py::test_bug030_the_brief_is_checked_again_after_the_slot_wait[True]` (the brief rewritten while the launch waits: exit 0 today, must be 125 with no run and no log row); `[False]` must run. `::test_bug030_a_ceiling_refusal_does_not_wait_for_the_slot` pins that the refusals come before the slot (passes today, must keep passing).
5. **mutation-run.py exits 1 on an import failure.** Root cause: `import tomllib` and `import bridge_env` run at module level in `bridge/cursor-bridge/mutation-run.py`, before `run_main`'s catch, which maps an internal error to 3; a traceback ends the program with exit 1, the survivor code. Reproduction: `tests/test_mutation_run_supervisor.py::test_bug030_an_import_failure_exits_3_never_1` (a lone copy of the program: exit 1 with ModuleNotFoundError today, must be 3 with a `mutation-run:` line and no traceback).
6. **The checkpoint run leaves out the new tests' conftest.py files.** Root cause: `archive_checkpoint` (`bridge/cursor-bridge/mutation-run.py`) copies the listed new test files, the root `.env` and the `untracked` paths over the commit's archive, never the working tree's conftest.py files on the way to a new test; `checkpoint_label_for_test` labels an `error` as `failing`, so a new test whose fixture is in a new or changed conftest.py errors on the old code, is listed `failing`, and the run exits 0. Reproduction: `tests/test_mutation_run_supervisor.py::test_bug030_the_checkpoint_run_takes_the_new_tests_conftest_files[False]` and `[True]` (a new and a changed tests/conftest.py: `failing`, exit 0 today, must be `passing on old code`, exit 4).
7. **A report named `<ID>-report.md` is read as a brief.** Root cause: `bridge_env.HANDOFF_REPORT_NAME` (`bridge/cursor-bridge/bridge_env.py`) matches only `-r<N>-report.md`; `<ID>-report.md` and the round-letter form `-r<N><letter>-report.md` are missed. Reproduction: `tests/test_bug030.py::test_bug030_a_report_file_is_never_a_brief_to_the_launcher` and `::test_bug030_the_pace_report_takes_no_report_file_for_an_increment`.
8. **review-guard.py's inputs take another ID's files.** Root cause: `review_inputs` (`bridge/cursor-bridge/review-guard.py`) keeps a name when `str(nnn) in name`, a substring test, so TASK-001's inputs hold TASK-001b's, TASK-001-r2's and XTASK-001's files. Reproduction: `tests/test_bug030.py::test_bug030_the_review_inputs_are_the_ids_own_files`.

Satisfies: R-040 — one heavy job at a time on the computer, through the launcher's machine-wide slot (causes 1, 2, 3, 4: the rows and the checks around the slot wait); R-041 — mutation reruns run through `mutation-run.py`, and the new tests run once against the checkpoint's code (causes 5, 6); R-042 — the code gate's round ceiling held by programs, each builder run of a brief `handoff/<ID>.md`, then `<ID>-r<N>.md` (causes 3, 4, 7, 8); R-044 — the pace section computed by `pace-report.py` from git and the launcher's and the guard's records (cause 7).
