## Summary

`push-scan.py` reads each commit of `<base>..HEAD` with read-only git, scans the message, the author and committer name and address, each added line, and each added or renamed file name for a path of this computer and for account names taken from the profile folder, the login, and the optional names file, drops a name equal to the remote owner or to the configured git identity, and prints only the commit, the place, and the kind.
