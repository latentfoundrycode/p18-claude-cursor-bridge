## Requirements

1. **Refuse a project whose top level would shadow a module importable outside it** (data integrity; behaviour against R-041 and `handoff/TASK-031-r6.md` item 3, B-3). In `copy_pytest_config_file`, before any candidate is looked at or read, list the copy root's top-level entries (names only). From each entry, derive the module name or names Python's path finder would import it as from that folder. `S` below is `importlib.machinery.all_suffixes()` on the running Python (source, bytecode and extension suffixes; on Windows, among others, `.py`, `.pyw`, `.pyc`, `.cp312-win_amd64.pyd`, `.pyd`; on Linux, `.cpython-312-x86_64-linux-gnu.so` and `.so`):
   - **A file whose name ends in a suffix of `S`:** the part of the name before that suffix. Do this for every suffix of `S` the name ends with. For example, `tomllib.cp312-win_amd64.pyd` ends both in `.cp312-win_amd64.pyd` and in `.pyd`, and it must yield `tomllib`.
   - **A folder holding a file named `__init__` plus a suffix of `S` (a regular package):** the folder's name.
   - **Anything else** yields no module. That covers a folder with no `__init__` file (a namespace portion, which a later regular package would beat) and a data file.

   A derived name shadows if it is a valid identifier (`str.isidentifier()`) and at least one of these holds:
   - it is in `sys.stdlib_module_names`;
   - it is in `sys.builtin_module_names`;
   - `importlib.util.find_spec(name)` returns a spec whose `origin` is not `None` in the program's own environment. A namespace spec (its `origin` is `None`) does not count: nothing is imported from it, and on this machine `find_spec("lib")` returns one, because Python's own install folder holds a `Lib` folder and Windows names are case-insensitive, so counting it would refuse the existing fixtures' `lib/` package (the supervisor checked: with this rule, of the fixtures' top-level names only `_pytest`, `iniconfig`, `json`, `pluggy` and `tomllib` are found).

   On the first shadowing name, raise `Refuse("mutation-run: a top-level module <name> in the project would shadow an installed or standard-library module")`, with `<name>` the derived module name. That ends the run with exit 2 before any mutant runs, with no cache line. The message text is fixed by this brief; keep it ASCII.
