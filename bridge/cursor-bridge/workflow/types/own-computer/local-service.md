# Local service

## Add at interface.variants

A part of this sub-type runs the interface phase's contract design variant for the protocol other software calls it through, `~/.claude/cursor-bridge/workflow/phases/interface/contract-design.md`: the first variant this sub-workflow activates, an addition and never a replacement. Where the part also has administrative commands a person types, it runs the command design variant for them too, `~/.claude/cursor-bridge/workflow/phases/interface/command-design.md`. Each variant is added for its own kind of interface, so a part with both runs both, never one in place of the other.
