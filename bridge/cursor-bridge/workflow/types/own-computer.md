# Software on your own computer

## Add at intake.questions

Software on your own computer has four sub-types, told apart by what its user meets it through: a window (GUI), a terminal (CLI), nothing, the part running jobs unattended with files or records as its output (pipeline), or other software on the same computer calling it through a protocol (local service). Ask which, where the owner's description leaves it open. A part met through several, such as a local service with administrative commands, takes the sub-type of the surface it exists for, and the interface phase runs a variant for each of its other kinds of interface; a part that exists for two equally fits two sub-types equally, which pauses the project as the classification at intake says.
