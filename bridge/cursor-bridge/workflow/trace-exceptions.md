# Trace exceptions

Entries use the form `- <kind> <id> <file> <heading>` where `<kind>` is `reword` or `new`, `<id>` is the increment id (e.g. `TASK-010`), `<file>` is a repository-relative path to the core or a workflow Markdown file, and `<heading>` is the section heading text. The supervisor-text increment that rewords or adds appends each entry after `## Entries`.

- new TASK-010 bridge/cursor-bridge/workflow/phases/reflection.md Project end
