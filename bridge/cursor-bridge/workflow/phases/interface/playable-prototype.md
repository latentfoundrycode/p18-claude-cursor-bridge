## Playable prototype

### What this variant is

The playable prototype is the interface phase's variant for play (`interface.md`, "The variants"): a game is judged by playing it, so its interface is approved by a playtest, where the owner plays the prototype and approves its feel or sends it back. Its procedure belongs to the Game Development type workflow, which replaces this phase for every part of the product type *video game* with its own (the open list, `video-game`; release E writes it, with its Roblox sub-workflow). The main workflow holds no procedure for play beyond this pointer.

No project reaches this phase needing it before that workflow exists: a part that is a video game is classified as one at intake, and a product type whose workflow is not yet written pauses the project there (`intake.md`, "Classifying each part"). Screens a game also has (menus, a shop, a settings screen) keep the mockups, approved as pictures inside the playtest's gate, as the Game Development workflow will state.
